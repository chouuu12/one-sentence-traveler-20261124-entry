One sentence explaining the modern internet to a traveler from 1800, written as a small Python program. Entry for the [make.fun "One Sentence for a Traveler from 1800" bounty](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) ($2 USDC, top 10 paid).

> Imagine a library where the book you seek opens on your table at once, and every reader may write in its margins.

## Run it

```sh
python3 main.py
```

This writes exactly that one sentence (113 characters, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set).
